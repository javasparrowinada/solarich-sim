# solarich 着せ替えシートシミュレーション

SOLARICH 1000 の着せ替えシートを、本体画像に合成して比較検討するための静的サイト。

公開URL: https://javasparrowinada.github.io/solarich-sim/

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（一覧・詳細・書き出し） |
| `app.js` | 合成処理・操作・保存・書き出し |
| `catalog.js` | カテゴリーと枠の定義（10カテゴリー × 10枠） |
| `assets/base.jpg` | ベース本体画像（4000×2780） |
| `assets/cutpass.svg` | シートの抜き型（カットパス） |
| `assets/print.svg` | 印字レイヤー（アイコン・文字・ロゴ） |

ビルド不要。ローカルで見るときは静的サーバー経由で開く（`file://` だと画像が読めない）。

```bash
cd ~/solarich-sim && python3 -m http.server 8765
```

## できること

- 色（RGB / HEX）または模様画像をシートに反映
- 印字（アイコン・文字・ロゴ）を 白 / 黒 / 任意の色 で切り替え
- 案ごとにイメージ画像（設置シーンの写真）を添付
- 版を10件まで保存し、名称を付けて切り替え（ブラウザ内 / IndexedDB）
- 書き出し … PDF（A4横）/ PNG（1920×1080）/ 共有用HTML（1ファイル完結）/ 単体PNG

## 抜き型と本体画像の位置合わせ

シートの領域は `assets/cutpass.svg` をそのままマスクとして使っている。
ベース画像上のどこに置くかは `app.js` の `MASK` / `SHEET` に定数で持たせている。

この値は、ベース画像の穴（ディスプレイ・USB-A×2・USB-C×2）の中心と、
抜き型側の対応する穴の中心を最小二乗で合わせて算出した（残差 0.8px 以下）。

**ベース画像を別アングル・別解像度のものに差し替えた場合は、この2つの定数を計算し直す必要がある。**

`assets/print.svg` は抜き型と同じ viewBox なので、`MASK` と同じ位置に重ねればよい。
印字要素は `.cls-3`、シート形状は `.cls-2`（`opacity:0`）。色は CSS の `fill` を差し替えて変えている。

## 制限

- 保存はブラウザごと。別のPCやブラウザからは見えない
- 共有はファイル（共有用HTML / PDF / PNG）を渡す方式。書き出した時点のコピーになる

## デプロイ時の注意（キャッシュ）

GitHub Pages はブラウザにファイルをキャッシュさせるため、更新しても古い画面が出ることがある。
`index.html` の `<script src="...?v=…">` と `app.js` 内の `assets/...?v=…` の数字を
更新のたびに揃えて変えること（日時を入れておけばよい）。

```bash
V=$(date +%Y%m%d%H%M)
sed -i '' -E "s|(catalog\.js\|app\.js)\?v=[0-9]+|\1?v=$V|g" index.html
sed -i '' -E "s|(assets/[a-z.]+)\?v=[0-9]+|\1?v=$V|g" app.js
```
